An unofficial, AI-assisted Pac-Land conversion for the Mega Drive / Genesis. This is a ROM maker: it contains no game. You supply your own MAME Pac-Land ROM set and it builds the cartridge on your computer.

## Downloads

| System | File | How to run it |
| --- | --- | --- |
| Windows 10/11 (64-bit) | `PacLand-ROM-Maker-Windows-x64.exe` | Double-click it |
| Linux (x86-64) | `PacLand-ROM-Maker-Linux-x64.AppImage` | Mark it executable, then run it |
| Mac (Apple Silicon) | `PacLand-ROM-Maker-macOS-Apple-Silicon.dmg` | Open the DMG and run the app inside (added once its build completes) |

Drop your `pacland.zip` (or the folder it is in) onto the window, choose where to save the cartridge and press **Build my ROM**. All build tools are included: nothing to install and nothing downloaded. The apps are not code-signed, so Windows may show "Windows protected your PC": choose *More info*, then *Run anyway*. `SHA256SUMS.txt` lists the checksums of the downloads.

## Your ROM set

Merged, split and non-merged MAME sets all work. Files are found by checksum, so ZIP and file names do not matter. A merged set already includes the Japanese character artwork; with a split set, keep `paclandj.zip` beside `pacland.zip`. If anything is missing, the maker lists exactly what it needs. With the Japanese artwork available, the cartridge is 4,063,232 bytes with SHA256 `68404d45d2db59210f9c46141d74c25df461c307f4f09600a213a28af57e6c80`.

## What's new since v1.0

- New desktop ROM maker for Windows, Linux and Apple Silicon Macs, contributed by [Anime0t4ku](https://github.com/Anime0t4ku): build tools included, choice of output folder, cancel button and build log.
- The game itself is unchanged from v1.0 (same cartridge, build 68404d45).

This is a development build: some frames still drop in the busiest scenes and the audio fidelity review is unfinished. See ISSUES.md.
